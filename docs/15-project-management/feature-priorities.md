# Feature Priorities
**Status:** Planned
- **Must have:** Authentication, role-based dashboard, catalogue, search/filter/sort, availability, physical copies, borrow/return, suggestions, voting, librarian dashboard, notifications.
- **Strong enhancements:** Reservations, waiting list, QR/barcode, fines, analytics, audit logs.
- **Future:** AI recommendations, natural-language search, email, library map, PWA/mobile, college SSO, advanced analytics.
- **Not now:** payment gateway, facial recognition, blockchain, full AI chatbot, RFID, native apps, microservices.
