# Project Objectives
**Status:** Planned

1. Make the library catalogue searchable and its availability visible in real time.
2. Model physical inventory correctly (book vs. copy) so availability is accurate.
3. Digitize borrowing: request → approval → issue → return, with due dates and history.
4. Let users join a waiting list when no copy is available.
5. Give the community a voice: suggestions and one-vote-per-user voting that measures demand.
6. Give librarians dashboards, reports and audit trails.
7. Enforce role-based access on the backend; protect user privacy.
8. Deliver a polished, demonstrable MVP for the hackathon rather than a large incomplete system.

## Success measure
The MVP is done when it meets the [acceptance criteria](../02-requirements/acceptance-criteria.md).
