# Glossary
**Status:** Planned

| Term | Meaning |
|---|---|
| Book | The bibliographic record (e.g. *Clean Code*). **Book ≠ Book Copy.** |
| Book copy | An individual physical copy of a book (Copy #001, #002…); has accession number, barcode/QR, shelf/rack, status, condition |
| Accession number | Library-assigned unique identifier of a physical copy |
| Loan | A borrowing transaction between a user and a physical copy |
| Reservation | A request for a currently unavailable book/copy |
| Waiting list | Ordered queue of users waiting for a book |
| Suggestion | A user's proposal for a new library book |
| Suggestion vote | A user's support for a suggestion (one per user per suggestion) |
| Catalogue | The searchable book collection |
| Availability | Current physical-copy availability of a book |
| RBAC | Role-based access control |
| MVP | Minimum viable product for the hackathon |
| ADR | Architecture Decision Record |
| Find My Book | Enhancement showing Library → Block/Floor → Rack → Shelf |
