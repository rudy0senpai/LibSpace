# Stakeholders
**Status:** Planned

| Stakeholder | Interest |
|---|---|
| Students | Discover, borrow, reserve, suggest, vote; track own loans |
| Faculty | Same user-level capabilities; may recommend books (reason: *Faculty Recommendation*) |
| Departments | Scoped, department-level reports/statistics; **no broader database-management rights than the librarian** |
| Librarians | Primary library management: books, copies, loans, returns, reservations, suggestions, reports, fines, audit logs |
| Admins / Super Admins | Platform configuration: roles, permissions, settings, librarian/admin accounts, session revocation, security/audit management |
| MITRC institution | Owner of real data, SSO (if any), borrowing rules — none supplied yet |
| Hackathon evaluators | Judge completeness of the ecosystem and demo |
