# Feature: Book Catalogue
**Status:** Planned · **Priority:** MVP
Searchable collection of bibliographic records with authors, category, publisher, ISBN, edition, language, year, description, cover reference. Book details page shows cover, title, author, description, ISBN, edition, publisher, year, language, category, rack/shelf, total and available copies, and request/reserve/waitlist actions. Never show borrower identity — e.g. only "2 copies currently borrowed". Files: `components/books/`, `pages/student/BookSearch.jsx`, `api/books.py`, `services/book_service.py`.
