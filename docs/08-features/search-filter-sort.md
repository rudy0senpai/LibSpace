# Feature: Search, Filter, Sort
**Status:** Planned · **Priority:** MVP
- **Search:** title, author, ISBN, category, publisher, keywords.
- **Filters:** category, author, publisher, year, language, availability (**Available Now**), department/relevance, edition.
- **Sort:** A→Z, Z→A, newest, oldest, most borrowed, recently added, highest rated (only if ratings exist).
- Paginated; index searched fields. Natural-language search is future scope.
