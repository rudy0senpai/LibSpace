# Acceptance Criteria — Definition of Done for the MVP
**Status:** Planned

The MVP is functional when:

- [ ] authentication works
- [ ] role-based access works
- [ ] students/faculty can search the catalogue
- [ ] books can have multiple physical copies
- [ ] availability is accurate
- [ ] librarian can manage books and copies
- [ ] users can request/borrow books
- [ ] librarian can approve, issue and return books
- [ ] loan history works
- [ ] due dates work
- [ ] users can suggest books
- [ ] users can vote on suggestions
- [ ] librarian can manage suggestions
- [ ] in-app notifications work
- [ ] unauthorized users cannot perform protected operations
- [ ] basic audit logging works
- [ ] core workflows are tested
- [ ] UI is usable and responsive

The [end-to-end demo flow](../09-workflows/end-to-end-demo-flow.md) must run without manual data fixes.
