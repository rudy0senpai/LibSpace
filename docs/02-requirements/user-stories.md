# User Stories
**Status:** Planned

## Student / Faculty
- As a user, I want to search by title, author, ISBN, category or publisher so I can find a book quickly.
- As a user, I want an **Available Now** filter so I only see borrowable books.
- As a user, I want to see rack and shelf so I can find the book physically.
- As a user, I want to request or reserve a book so I can borrow it or wait in line.
- As a user, I want to see my due dates and loan history so I avoid overdue fines.
- As a user, I want notifications for due-soon, overdue and reservation-available so I don't miss anything.
- As a user, I want to suggest a book and state why the library should add it.
- As a user, I want to vote on others' suggestions to show demand (one vote each).
- As a user, I want to manage my own profile.

## Department
- As a department representative, I want scoped reports/statistics for my department without database-management rights.

## Librarian
- As a librarian, I want to manage books, authors, categories, publishers and physical copies.
- As a librarian, I want to approve requests, issue and receive books.
- As a librarian, I want to see overdue, lost and damaged items.
- As a librarian, I want to review suggestions with demand data and set their status.
- As a librarian, I want dashboards and reports to plan acquisitions.
- As a librarian, I want audit logs of administrative actions.
- As a librarian, I want to scan a copy's QR/barcode to issue or return it quickly.

## Admin
- As an admin, I want to configure roles, permissions and settings, manage librarian/admin accounts and revoke sessions.
