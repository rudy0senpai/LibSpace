# End-to-End Demo Flow (Hackathon)
**Status:** Planned

```text
Student Login → Dashboard → Search "Machine Learning" → Filter Available → Open Book
→ View Availability + Rack → Request Book → Librarian Dashboard → Approve Request
→ Book Issued → Student Notification → Student Suggests Another Book
→ Other Users Vote → Librarian Reviews Demand → Suggestion Approved
→ Book Eventually Added to Catalogue
```
The demo should show the complete ecosystem, not isolated CRUD screens. Requires seed/mock data ([seed data](../05-database/seed-data.md)).

## Central loop
DISCOVER → BORROW → RETURN → SUGGEST → VOTE → ACQUIRE → DISCOVER
